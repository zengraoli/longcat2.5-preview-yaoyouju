# 腰有据 · 后台管理系统

Vue 3 + Vite + TypeScript + Pinia + Vue Router。

## 启动

```bash
npm install
npm run dev        # 开发，http://localhost:5403（代理 /api 到 server 3400）
npm run build      # 构建（含类型检查）
npm run typecheck  # 类型检查
```

- 需要先启动 server（`server/` 目录，端口 3400）。
- 登录：账号密码 + TOTP（演示固定码 `123456`）。
