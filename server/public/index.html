腰有据 · API 接口文档

统一响应格式：{"code": 0, "data": ..., "message": "ok"}；出错时 code 非 0，message 为中文。时间一律 UTC ISO8601。

全局约定

约定说明
用户登录态Authorization: Bearer <token>（手机号验证码登录，验证码固定 123456）
后台登录态X-Admin-Token: <token>（账号密码 + TOTP，演示固定码 123456）
错误码1001 参数错误 / 1002 未登录 / 1003 无权限 / 1004 不存在 / 1005 状态冲突 / 1006 锁定 / 2001 验证码错误 / 3001 红旗 / 3002 停止个性化 / 3003 开关关闭 / 4001 评测门禁 / 5001 内部错误 / 5003 服务不可用
脱敏手机号在列表、日志、非本人接口中脱敏为 138****1234

授权 auth

方法路径说明
POST/auth/sms-code发送短信验证码（演示固定 123456，只写日志且脱敏）
POST/auth/login手机号验证码登录，返回 token 与三项同意记录
GET/auth/consents当前用户的同意记录（可查）
POST/auth/consents单独勾选 / 撤回同意（撤回立即生效）

安全 safety

方法路径说明
GET/safety/tips就医提示（无需登录，不被任何流程阻断）
POST/safety/check安全预检：红旗信号与服务范围校验，命中写安全事件

病程 episodes

方法路径说明
GET/episodes病程列表
POST/episodes创建病程
GET/episodes/:id病程详情
GET/episodes/:id/events病程事件列表
POST/episodes/:id/events新增病程事件（报告/症状/医嘱/行动/结局）
PUT/episodes/events/:eventId纠正自己的记录
DELETE/episodes/events/:eventId删除自己的记录
GET/episodes/:id/timeline时间线
GET/episodes/:id/symptom-logs记录今天的列表
POST/episodes/:id/symptom-logs记录今天（允许跳过，缺失为"尚未确认"，不复用昨日答案）

报告 reports

方法路径说明
POST/reports录入报告（粘贴文字为主，抽取术语与位置）
POST/reports/ocr拍照提取（模拟 OCR，返回示例文本）
GET/reports/:id报告详情（含术语与原文位置）
GET/reports/:id/verify结构化核对（来源、时间、核实状态、冲突项）
PUT/reports/:id/confirm用户确认报告（解决冲突项）

分析 analyses

方法路径说明
POST/analyses提交分析：安全校验 → 开关检查 → 入队，返回 202 与任务 ID（附安全提示）
GET/analyses/:id查询分析结果（五段 + 引用 + 版本快照）或任务状态；失败返回回退状态

分析由独立 Worker 进程（npm run worker）轮询消费；不启动 Worker 时任务保持排队。

问与解释 qa

方法路径说明
POST/qa/sessions创建会话（基于当前分析）
GET/qa/sessions会话列表
GET/qa/sessions/:id会话历史
POST/qa/sessions/:id/messages提问（越界明确不答；反复求保证时稳定解释并结束本轮）
POST/qa/sessions/:id/followup-questions一键加入复诊问题
GET/qa/sessions/:id/followup-questions已加入的复诊问题

复诊摘要 followup

方法路径说明
GET/followup/summary?episodeId=预览（固定六段，不保存）
POST/followup/summary保存/更新摘要
PUT/followup/summary/:id纠正摘要
PUT/followup/summary/:id/questions问题清单排序
POST/followup/summary/:id/export导出（记录导出时间与格式；PDF 由前端打印生成）
