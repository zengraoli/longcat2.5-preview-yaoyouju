# 错误码登记

统一响应格式：`{"code": 0, "data": ..., "message": "ok"}`；出错时 `code` 非 0，`message` 为中文。

| code | HTTP | 含义 | 触发场景 |
|-|-|-|-|
| 0 | 200 | 成功 | - |
| 1001 | 400 | 参数校验失败 | 请求体不符合 DTO 校验 |
| 1002 | 401 | 未登录或会话过期 | 缺少 / 过期登录态 |
| 1003 | 403 | 无权限 | 越权访问（含未同意健康信息处理时使用分析功能） |
| 1004 | 404 | 资源不存在 | 记录不存在或不属于当前用户 |
| 1005 | 409 | 状态冲突 | 非法状态流转、重复提交 |
| 1006 | 423 | 账号已锁定 | 后台连续登录失败 |
| 1007 | 429 | 请求过于频繁 | 触发限流 |
| 2001 | 400 | 验证码错误 | 短信验证码不正确 |
| 2002 | 400 | 同意记录缺失 | 未单独同意健康信息处理 |
| 2003 | 400 | 后台账号或密码错误 | 后台登录失败 |
| 2004 | 400 | 后台 MFA 验证码错误 | TOTP 不正确 |
| 2005 | 400 | 双人确认未通过 | 发布 / 批量下线需第二人确认 |
| 3001 | 400 | 命中红旗信号 | 安全规则引擎判定需提示就医 |
| 3002 | 400 | 停止个性化分析 | 安全规则引擎判定越界或停止个性化 |
| 3003 | 400 | 功能开关关闭 | 个性化分析等开关关闭 |
| 4001 | 400 | 评测门禁未通过 | 模型发布被阻断 |
| 4002 | 400 | 证据已停用 | 引用已停用证据 |
| 5001 | 500 | 服务内部错误 | 未分类异常 |
| 5002 | 503 | 服务不可用（回退） | 模型 / 检索 / 来源校验失败 |
