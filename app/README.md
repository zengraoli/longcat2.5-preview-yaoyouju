# 腰有据 · App

uni-app（Vue 3 + Vite + TypeScript）实现的用户端 App。

## 启动方式

### H5 开发
```bash
npm install
npm run dev:h5
```

### H5 构建
```bash
npm run build:h5
```

### 微信小程序
```bash
npm run dev:mp-weixin
```
